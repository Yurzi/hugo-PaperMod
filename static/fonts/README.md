# Bundled fonts

- **LXGW WenKai Mono GB Screen v1.522** — sourced from the [LXGW WenKai Screen v1.522 release](https://github.com/lxgw/LxgwWenKai-Screen/releases/tag/v1.522). The official TTF was converted losslessly to WOFF2 for web delivery. Its SIL Open Font License is included in `lxgw-wenkai/OFL.txt`.
- **Maple Mono NF v7.9 (unhinted)** — sourced from the [Maple Mono v7.9 release](https://github.com/subframe7536/maple-font/releases/tag/v7.9), using the upstream `MapleMono-NF-unhinted.zip` build. The official TTF files were converted losslessly to WOFF2 for web delivery. Its SIL Open Font License is included in `MapleMono/LICENSE.txt`.
