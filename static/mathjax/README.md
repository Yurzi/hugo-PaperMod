# Bundled MathJax runtime assets

These files support the local **MathJax 4.1.3** fallback loaded by `assets/js/tex-mml-chtml.js`:

- `fonts/mathjax-newcm-font/chtml/` comes from `@mathjax/mathjax-newcm-font@4.1.3` and provides local CHTML font data and WOFF2 files.
- `input/` and `sre/` come from `mathjax@4.1.3` and provide dynamically loaded input extensions and speech-rule resources.

The upstream MathJax license is included in `LICENSE`.
